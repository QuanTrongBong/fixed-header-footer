# Fixed Header & Footer

Trang thực hành HTML/CSS minh họa thanh điều hướng cố định ở đầu màn hình và footer cố định ở cạnh dưới khi cuộn trang.

## Chạy trang

Mở `index.html` trong trình duyệt. Không cần cài thư viện hoặc build project.

## Điểm chính

- Header dùng `position: fixed` và `top: 0`.
- Footer dùng `position: fixed` và `bottom: 0`.
- Nội dung có khoảng đệm để tránh bị che bởi header/footer.
- Menu liên kết đến các phần trong trang; bố cục thích ứng với màn hình nhỏ.
